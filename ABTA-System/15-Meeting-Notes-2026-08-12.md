## 1. สรุปที่ประชุมตกลง

### ระบบสมาชิก / ผู้ประกอบการ

- สมาชิกกรอกข้อมูลผ่าน **LINE OA**
- เมื่อมีการกรอก → **แจ้งเตือนเจ้าหน้าที่**
- Admin ตรวจสอบและจัดการข้อมูลใน **Back Office**
- ต้องการรองรับการกรอกข้อมูลจาก **หลังบ้าน (Admin)** ด้วย

### ระบบใบเสร็จ

- ออก **เลขที่ใบเสร็จ** ตามระบบ
- มี **เลขผู้เสียภาษี / ข้อมูลภาษี**
- **ค้นหาใบเสร็จ** ได้
- ออก **PDF ทางการ**
- ใบเสร็จจริงต้อง **ยืนยัน/อนุมัติก่อน** — ก่อนอนุมัติ = ชั่วคราว แก้ไขได้

### การทดลองใช้งาน

- **อาทิตย์หน้า** ต้องการขึ้นระบบให้ทดลอง
- ให้ **กรรมการ** ทดลองก่อนเปิดจริง
- ทดสอบครบ: กรอกข้อมูล → แจ้งเตือน → ตรวจหลังบ้าน → เลขใบเสร็จ → ค้นหา → PDF

### สิทธิ์การเข้าใช้งาน

- เข้า Back Office ด้วย **Google (อีเมล)**
- กำหนดสิทธิ์: Owner / Admin / กรรมการ (ในระบบใช้ admin / นายทะเบียน / เหรัญญิก)
- มีข้อเสนอ **ล้างข้อมูลทดลอง** สำหรับ Owner — **ตกลงว่ายังไม่ทำตอนนี้**

### เอกสารประกอบ

- ขอ **คลิปการประชุม** ส่งให้ทีมพัฒนารับทราบ

### 4.2 ใบเสร็จ & PDF

| รายการ | สถานะ | รายละเอียด |
|--------|--------|------------|
| เลขใบเสร็จอัตโนมัติ `RC-T-…` → `RC-…` | ✅ ทำแล้ว | ชั่วคราวเมื่ออนุมัติข้อมูล / จริงเมื่ออนุมัติสลิป |
| ใบเสร็จชั่วคราว vs จริง (ยืนยันก่อนออกจริง) | ✅ ทำแล้ว | ตรง flow ที่ประชุมพูด |
| หน้าใบเสร็จ HTML + พิมพ์/บันทึก PDF | ✅ ทำแล้ว | `/receipt` — ใช้ `window.print()` |
| สมาชิกเปิดใบเสร็จจาก LINE | ✅ ทำแล้ว | ลิงก์จากสถานะ / ข้อความยืนยัน |
| **Admin ค้นหาใบเสร็จ** (เลขที่ / ยอดเงิน) | ✅ ทำแล้ว (12 ส.ค.) | `/admin/receipts` |
| **Admin จัดการใบเสร็จ / PDF** ใน Back Office | ✅ ทำแล้ว (12 ส.ค.) | เปิดใบเสร็จ + ปุ่ม PDF (payment-scoped) |
| เลขผู้เสียภาษี / ข้อมูลภาษีบนใบเสร็จ | ❌ ยังไม่ทำ | ยังไม่มีในโมเดลข้อมูล |
| PDF ไฟล์จากเซิร์ฟเวอร์ (template ทางการ) | ❌ ยังไม่ทำ | วาง Phase 2 — รอบนี้ใช้พิมพ์จากเว็บ |

**สรุปใบเสร็จ:** ระบบออกเลข + แสดงหน้าเว็บ + พิมพ์ PDF ได้แล้ว — **ส่วนที่ยังขาดคือ Admin ค้นหาและจัดการใบเสร็จใน Back Office**

### 4.3 แจ้งเตือน

| รายการ | สถานะ | รายละเอียด |
|--------|--------|------------|
| โค้ด push แจ้ง staff ทาง LINE | ✅ ทำแล้ว | `staff-notify.ts` |
| เหตุการณ์: สมัคร / ต่ออายุ / สลิปใหม่ / สัมมนา | ✅ ครบ | |
| ตั้งค่า `STAFF_LINE_USER_IDS` | ⬜ **รอใส่** | ถ้าว่าง = **ไม่มีใครได้รับแจ้งเตือน** |
| แยกแจ้ง **นายทะเบียน vs เหรัญญิก** คนละ LINE | ❌ ยังไม่ทำ | ตอนนี้ยิงไปรายการเดียวกันทั้งหมด |
| แจ้ง **กลุ่ม LINE Admin** | ❌ ยังไม่ทำ | ตกลงใช้แจ้งรายคน |

**วิธีตั้งค่าแจ้งเตือน (เมื่อพร้อม):**

```env
# Firebase Functions environment
STAFF_LINE_USER_IDS=Uxxxx,Uyyyy,Uzzzz
```

- ใส่ LINE User ID ของนายทะเบียน / เหรัญญิก / แอดมิน (คั่นด้วย comma)
- ต้องมี Messaging API token ใน `.env` ด้วย
- หา User ID: ให้เจ้าหน้าที่ add OA แล้วส่งข้อความ → ดูจาก log

## 6. Flow ทดสอบที่กรรมการควรลอง

```
สมัคร/ต่ออายุ (LINE)
    → แจ้งเตือน staff (LINE)
        → Admin ตรวจข้อมูล (นายทะเบียน)
            → Admin ตรวจสลิป (เหรัญญิก)
                → ออกเลขใบเสร็จ
                    → Admin ค้นหาใบเสร็จ  ← ยังไม่มี
                        → เปิด PDF / พิมพ์
```
